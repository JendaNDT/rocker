# W33 — Daily/AI plans, exact resume and Live

The overview opens exact lessons, drills and owned riffs, retains the last practice
task and persists independently the current daily and accepted-AI plan completion.
The footer returns to the plan and lets the user explicitly mark a block once;
manual completion neither grades audio nor adds time. The next unfinished block
is offered. Lessons restore their saved step. Live now includes a large fresh-input
chromatic tuner alongside shared amp/metronome/recording controls and real meters.
A single native audio host and capture controller serve every view.

An optional Windows execution-state request applies only to the running explicit
practice session and releases on pause/end/suspend/close. No global OS setting is
modified. Native checks exercise plan routes, once-only persistence and Live widgets.
Two domain checks cover independent completion/resume and rejection of external
saved routes. Hardware, actual sleep and manual plan acceptance remain deferred.
