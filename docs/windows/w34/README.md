# W34 — Settings and first-run wizard

Six native steps cover profile, optional legacy import, interface/channel, explicit
signal start, monitoring and local persistence. A clean profile opens the wizard;
steps persist, may be skipped without device/key/network, and can be revisited.
Only explicit buttons start input or the separately labelled low-level 440-Hz demo.
The demo never supplies fake detector readings.

Settings link all actual device/tuner/profile options, explain changes that restart
audio, provide system/dark/light Vintage, Zen, session-only keep-awake, protected AI
keys, diagnostics, the actual data folder, backups and wizard return. A scoped
appearance/session reset does not erase profile, progress, media or keys. Arbitrary
live relocation of the open database is deliberately unavailable; native project
save paths and backup/restore are the supported file workflows.

Native smoke constructs every wizard step, settings and reopened onboarding state
without a key/device. Domain checks reject an invalid step and preserve completion.
Manual first-run/audio acceptance remains deferred; no device test is claimed.
