# W36 — Native design across 32 views

Every view now routes to its implemented service-backed native workspace; obsolete
placeholder/catalog fallbacks are removed. A missing implementation fails explicitly.
The [matrix](view-matrix.json) links each original acceptance scenario to its actual
implementation. Construction alone is not a claim of human/hardware acceptance.

Vintage retains Windows menus, fields, lists and file dialogs; instrument widgets
use themed faces. Live uses adaptive columns with tuner/input/monitoring visible
before advanced diagnostic details. The session footer remains compact in smaller
windows. AI plan targets use human task choices, not editable internal IDs, and
exact tuning/preset/drill navigation applies the selected task.

The Windows smoke captures all 32 real views, 640/1280/1680 layouts and light/dark
variants into an artifact gallery. The screenshots contain a disposable synthetic
profile, labelled preview content and real service states; they are not fabricated
illustrations. Screenshot review and Windows validation are pending. Manual keyboard,
Narrator, high contrast and physical guitar acceptance remain explicitly unperformed.
