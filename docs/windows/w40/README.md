# W40 — native access, local data and distribution audit

Native editors, dialogs and lists use Windows controls. ValueDial exposes a labeled Slider and NumberBox, the fretboard has one tab stop with arrow navigation and full string/fret/note names, and chord diagrams include a text equivalent. Authored controls are given meaningful UI Automation names from their visible labels. The Windows check traverses all 32 pages and queries actual UI Automation peers, plus Invoke/RangeValue patterns; manual Narrator, full keyboard traversal, high contrast and physical DPI remain deferred. High-contrast resources use Windows system color tokens and text uses system font resources.

Settings now documents all outbound behavior. There is no Rocker telemetry or background updater. Offline audio/lessons/projects do not require a connection. AI sends a user-initiated request, selected history and only explicitly selected statistics/profile; no audio files. Secrets are DPAPI-protected per provider/current account and omitted from export. Official embedded YouTube has its own cookies/network services; it never sends captured guitar audio. Diagnostics are saved and shared manually, with the W20 privacy contract. The browser migration helper reads only the user's selected PWA origin; it neither uploads nor changes original records.

Existing malicious archive/path/reparse-point, hash, bounded XML/notation, MIDI/container, YouTube-origin/token/message and mocked HTTP redirect/key/error tests cover imports and service boundaries. These are not a live provider/video result.

`windows/license-audit.ps1` inventories the exact restored NuGet versions/license declarations and hashes every published EXE/DLL. Package creation includes full notices from actual packages/runtime packs, JUCE/ASIO, Ogg/Opus, zlib, stretch, libwebm, AlphaTab/Skia/HarfBuzz and OFL fonts. The MIT PWA exporter notice is included separately. Corresponding pinned source archives are separate from the installer. AlphaTab/MPL and JUCE/AGPL sources are available in that archive; no modified vendor code is distributed. Inno Setup 6.7.3's official license permits private and commercial use; its unchanged notice and pinned release SHA256 are recorded here and in `windows/installer/toolchain.json`.

The package audit must actually pass on the resulting Windows package. The installer is unsigned: this does not establish compatibility with enabled Smart App Control. No global protection change is requested.
