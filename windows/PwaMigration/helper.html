Převod z původního Rockeru

Pomocník čte pouze data Rockeru v tvém původním prohlížeči. Původní data nemaže, nikam je neodesílá a AI klíč do exportu nepřibalí.

  1. Zobraz v prohlížeči lištu záložek (Ctrl+Shift+B).
  2. Přetáhni následující odkaz na lištu záložek: Rocker — export pro Windows
  3. Otevři původní webovou aplikaci Rocker ve stejném prohlížeči a profilu, kde máš uložené cvičení a nahrávky.
  4. Klikni na novou záložku a potvrď export. Stáhne se soubor .rockermigration.
  5. Ve Windows Rockeru otevři Zálohy a soubory → Převod z webové aplikace a vyber tento soubor. Nejdřív uvidíš náhled; webová data zůstanou dostupná.

Pokud používáš už aktualizovanou webovou verzi s tlačítkem „Exportovat pro Windows včetně nahrávek“, můžeš použít přímo toto tlačítko. Stará záloha JSON neobsahuje nahrávky. Při odmítnutí záložky nastavením prohlížeče nic neobcházej; použij tlačítko exportu nebo původní JSON zálohu a nahrávky exportuj zvlášť.

Otevření této stránky samo nic nečte ani nezmění. Pomocník se spustí až záložkou na stránce původního Rockeru.
